# Gear & Enhancement

Gear is a primary progression pillar.

## Sacrifice ritual

A player selects one target gear item and at least two additional gear pieces. The target plus all sacrifices are consumed by the attempt.

- Success: the target's identity and rolled properties return in an enhanced state.
- Failure: the selected target can be destroyed at configured risk tiers.
- Every consumed piece generates Gear Fragments.
- High-value failures can seed a Lost Relic.
- Lost Relics are weaker echoes of the destroyed item's original power.
- Relics can enter the world pool and become exploration or global-event content.

## Core Weapons

Operatives can receive a personal Core Weapon. Equipping it exposes the weapon's hidden Talent Tree. Rarity controls tree depth and complexity.

## Visual composition

Base Item + Rarity Frame + Enhancement Frame + Glow + Particles + Awakened Overlay.

The client composes visuals from server-provided item state; it never determines enhancement outcomes.
